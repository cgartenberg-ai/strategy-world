# Strategy world

A static copy of the presenter app (strategy landscape, roadmap and concepts), for GitHub Pages. Open `index.html` from the site address; `roadmap/`,
`stages/` and `questions/` open those sections directly (add `?show=1` for show mode).

Generated by `tools/make_site.sh` in the app folder; edit the app there, not here, then re-run that script.
